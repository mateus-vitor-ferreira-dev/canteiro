# CANTEIRO — Frontend

A interface do jogo em **React 19 + TypeScript**, rodando no navegador. Ela só desenha o estado que o backend manda e envia as teclas do jogador: **nenhuma regra de jogo mora aqui**.

**Por enquanto a pasta está vazia.** O projeto React entra num próximo PR. A estrutura prevista e o protocolo com o backend estão no [README principal](../README.md#-estrutura-de-pastas) e na [especificação](../docs/ESPECIFICACAO.md#35-protocolo-entre-backend-e-frontend).
